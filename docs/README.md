# Documentation

This directory contains the source material for the public project documentation of PyGS.

## Contract

Use this directory to explain the project as a scientific software artifact:

* package scope;
* installation and usage;
* mathematical and physical conventions;
* examples and tutorials;
* public roadmap;
* curated references that affect the project.

## Map of contents

* [roadmap.md](roadmap.md): staged project direction and scope boundaries.
* [theory.md](theory.md): mathematical and physical conventions.

Future files:

* [bibliography.bib](./bibliography.bib): machine-readable bibliography, only if documentation tooling requires it.

## Future deployment

This directory is intended to become the source of the GitHub Pages documentation site.

Documentation tooling (*MkDocs + Material + mkdocstrings*) should be added only after the package has stable examples and enough public-facing material to justify deployment.
