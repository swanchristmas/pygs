# Decisions

This directory records development decisions that guide how PyGS is built.

## Contract

Use this directory to constrain future diffs, including:

* AI-assisted development workflow;
* code style choices;
* dependency policy;
* testing policy;
* documentation policy;
* architecture decisions;
* rejected alternatives.

## Relation to other files

* [AGENTS.md](../AGENTS.md) gives concise execution rules to coding agents.
* [docs/](../docs/) presents the project result.
* [notes_local/](../notes_local/) stores private local notes that should not define project behavior.

## Map of contents

* [development.md](./development.md): AI-assisted development workflow and review boundary.
* [code-style.md](./code-style.md): Python style choices and formatting conventions.
* [documentation-style.md](documentation-style.md): Documentation style choices including markdown conventions.
